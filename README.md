# Projeto Unity - JI_Tutorial

## :santa: Santa Run

**O tempo está correndo e o futuro do Natal está nas suas mãos!**

Em **Santa Run**, você assume o papel do Papai Noel em uma missão de emergência polo adentro. Os **cristais mágicos** que alimentam a magia do Natal foram espalhados pela neve. Sua missão é recuperar todos eles antes que seja tarde demais — mas o Polo Norte esconde seus próprios perigos!

### :warning: **O Perigo na Neve**

Um **Malvado Boneco de Neve** está à solta para estragar as festas!

Por sorte, a visão dele é bem curta: ele só vai começar a persegui-lo furiosamente se você chegar muito perto. Mantenha o olho atento, use as árvores do cenário para se esquivar e planeje bem o seu caminho!

### :dart: **Destaques do Jogo**

* :stopwatch: **Corrida Contra o Tempo:** Você tem exatamente **100 segundos** para coletar todos os cristais mágicos. Cada segundo conta!
* :ice_cube: **Inimigo com Mecânica de Visão:** O Boneco de Neve é lento de vista, mas implacável quando te enxerga. Mantenha a distância!
* :evergreen_tree: **Labirinto Natural:** Desvie de árvores e obstáculos nevados enquanto traça a rota perfeita.
* :christmas_tree: **Clima Natalino e Tenso:** Uma mistura divertida de ambientação festiva com a tensão de um jogo de sobrevivência arcade.

### :joystick: **Como Jogar**

1. **Explore o mapa** e procure os cristais mágicos brilhantes na neve.
2. **Dê a volta nos obstáculos** (como as árvores) para não perder velocidade.
3. **Fique atento ao Boneco de Neve:** se chegar muito perto da área de visão dele, corra!
4. **Colete todos os cristais antes dos 100 segundos acabarem** para salvar o Natal!
